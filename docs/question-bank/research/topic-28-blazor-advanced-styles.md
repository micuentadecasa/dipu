# Topic 28 research — Blazor advanced components and styles

**Research date:** 2026-10-12  
**Primary source:** Microsoft Learn, ASP.NET Core 10.0 Blazor documentation (`BLAZOR-10`).

## Official pages checked

- [Razor components](https://learn.microsoft.com/en-us/aspnet/core/blazor/components/?view=aspnetcore-10.0): component classes, Razor syntax, parameters, child content, references, attributes, raw HTML, and dynamic rendering context.
- [CSS isolation](https://learn.microsoft.com/en-us/aspnet/core/blazor/components/css-isolation?view=aspnetcore-10.0): `.razor.css`, bundling, child-component boundaries, `::deep`, preprocessor support, RCL support, scope identifiers, and MSBuild configuration.
- [Templated components](https://learn.microsoft.com/en-us/aspnet/core/blazor/components/templated-components?view=aspnetcore-10.0): `RenderFragment`, `RenderFragment<TValue>`, `@typeparam`, `Context`, and reusable templates.
- [Rendering](https://learn.microsoft.com/en-us/aspnet/core/blazor/components/rendering?view=aspnetcore-10.0): render flow, `ShouldRender`, `StateHasChanged`, external callbacks, and render suppression.
- [Lifecycle](https://learn.microsoft.com/en-us/aspnet/core/blazor/components/lifecycle?view=aspnetcore-10.0): parameter assignment, initialization, parameter-set callbacks, after-render callbacks, disposal, prerendering, and error handling.

The 100 objective statements and five 20-question candidate specifications are limited to claims represented by those official pages. Each candidate cites `BLAZOR-10`; independent review must recheck the exact heading/citation before promotion.
